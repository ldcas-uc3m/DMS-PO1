Para la visualización de la información, se creará una aplicación web. Ésta aplicación tendrá una arquitectura \textit{backend for frontend}, la cual tiene dos componentes principales: un \textit{frontend}, el cual será el encargado de la interfaz visual de la aplicación, y un servidor \textit{backend}, el cual será el encargado de realizar las consultas a las diferentes fuentes de datos.



\subsection{Descripción de la integración de datos}
Los datos serán extraídos a través de tres tipos de procesos distintos: \textit{web scraping}, uso de APIs externas, y uso de fuentes de datos estáticos.

Los datos procedentes de páginas web serán extraídos mediante el uso de \textit{web scraping}. Dado que éste es un proceso poco preciso, debido a la dificultad para obtener resultados acertados o válidos, los datos serán extraídos, filtrados, y agregados en un \textit{data warehouse}, y serán procesados en el momento de la consulta. Este último procesado se realizará de esta manera debido al gran volumen de datos no estructurados que puede suponer el uso de este proceso de extracción.

Los datos procedentes de APIs externas usarán un \textit{wrapper} por fuente, el cual será el encargado de extraer y transformar la información, homogeneizándola y poniéndola en un formato común.

Los datos estáticos obtenidos de las fuentes de datos serán extraídos, transformados, y almacenados en una base de datos no relacional, para su posterior consulta. Los datos multimedia serán procesados mediante el uso de Inteligencia Artificial, específicamente redes de neuronas, para filtrar y categorizar datos relevantes.


Podemos dividir las distintas fuentes de datos en tres tipos, dependiendo de qué proceso vamos a seguir para su extracción.


\subsubsection*{\textit{Web scraping}}
\begin{itemize}
  \item MUFON (Mutual UFO Network) \cite{mufon-scraping}: MUFON es una de las redes más grandes de investigación de OVNIs, con una base de datos privada muy extensa con avistamientos por miembros de la asociación. Permite consultar los 20 reportes más recientes.
  \item NUFORC (National UFO Reporting Center) Dataset \cite{nuforc-scraping}: El National UFO Reporting Center es una página web recolectando y clasificando reportes de avistamientos de OVNIs desde la década de 1950. Permite acceder a su base de datos mediante búsquedas en su web.
  \item UFO Stalker \cite{ufostalker-scraping}: Recolecta reportes de avistamientos en su base de datos, que se puede ver en su web o mostrar en un mapa.
  \item SatNogs Data \cite{satnogs-scraping}: Aplicación web permitiendo un acceso a una base de datos unificada y colaborativa, con datos de localización y transmisiones de objetos espaciales artificiales (satélites y naves espaciales)
  \item SETI (Search for Extraterrestrial Intelligence) Data \cite{seti-scraping}: SETI almacena datos relacionados con la vida extraterrestre recogidos por satélites, permitiendo buscar y descargar estos datos de gran tamaño en su aplicación web.
  \item ESA Sky Data Hub \cite{esa-sky-scraping}: Plataforma de datos espaciales que incluye imágenes del espacio profundo
  \item NASA Astronomy Picture of the Day (APOD) Random \cite{nasa-apod-scraping}: Acceso aleatorio a la colección de imágenes astronómicas diarias proporcionadas por la NASA.
\end{itemize}


\subsubsection*{Datos estáticos}
\begin{itemize}
  \item ESA NEO (Near Earth Object) Database \cite{esa-neo-db}: Esta base de datos de la ESA se actualiza periódicamente para mostrar los NEO más recientes o más próximos en el tiempo. Los datos mostrados en la web pueden descargarse en varios formatos de archivo distintos.
  \item NASA NEOS (Near Earth Object Studies) Database \cite{nasa-cneos-db}: Esta base de datos de la NASA se actualiza periódicamente para incluir NEOs o actualizar datos de los NEO registrados. Los datos se pueden filtrar de varias maneras en la web antes de poder descargarse en varios formatos de archivo distintos.
  \item NASA Fireballs Database \cite{nasa-fireballs-db}: Esta base de datos de la NASA se actualiza periódicamente para incluir bolas de fuego o bólidos detectados por sensores de la NASA. Los datos se pueden descargarse en varios formatos de archivo distintos.
  \item NASA Meteorite Database \cite{nasa-meteorite-db}: Esta base de datos de la NASA se actualiza muy poco, para incluir nuevos impactos de meteorito registrados. Los datos se pueden descargarse en varios formatos de archivo distintos.

  \item ESA (European Space Agency) Open Data \cite{esa-open-db}: La ESA proporciona acceso abierto a sets de datos que incluyen imágenes satelitales, mediciones climáticas, y muchos otros tipos de datos espaciales.
\end{itemize}


\subsubsection*{APIs externas}
\begin{itemize}
  \item SatNogs API \cite{satnogs-api}: API para extraer información de la base de datos unificada y colaborativa, con datos de localización y transmisiones de objetos espaciales artificiales (satélites y naves espaciales)
  \item SETI (Search for Extraterrestrial Intelligence) API \cite{seti-api}: SETI almacena datos relacionados con la vida extraterrestre recogidos por satélites, permitiendo buscar y descargar estos datos de gran tamaño mediante una API.
  \item NY2O API \cite{ny2o-api}: API de accesos limitados (1000 peticiones/h) sobre objetos espaciales para extraer su información TLE\footurl{https://en.wikipedia.org/wiki/Two-line\_element\_set}, o predecir su posición futura o localizaciones terrestres que sobrevolará.

  \item Google Maps API \cite{google-maps-api}: APIs de mapas de Google que te permite renderizar mapas interactivos con coordenadas geográficas.
  \item Google Maps Geocoding API \cite{google-maps-geocoding-api}: API de Google Maps utilizada para convertir nombres de lugares en coordenadas gegográficas.
  \item Mapbox APIs \cite{mapbox-api}: Proporciona mapas interactivos y herramientas de geolocalización personalizables, útiles para representar los datos.

  \item NASA Image and Video Library API \cite{nasa-media-library-api}: Proporciona acceso a una vasta colección de imágenes, videos y audios relacionados con misiones espaciales de la NASA.
  \item NASA Astronomy Picture of the Day (APOD) API \cite{nasa-apod-api}: Acceso a la colección de imágenes astronómicas diarias proporcionadas por la NASA.
  \item Sentinel Hub API \cite{sentinel-api}: Acceso a la colección de imágenes satelitales terrestres de los satélites Sentinel de la ESA.

  \item NASA open-access APIs\cite{nasa-open-api}: La NASA ofrece una variedad de APIs que cubren datos astronómicos, imágenes, videos y mucho más.
\end{itemize}

\subsection{Descripción del sistema propuesto}
% en ejecución; incluir la descripción de cómo debería funcionar el sistema, como tomaría los datos, como los actualizaría, cómo interactúa el cliente, etc.
El sistema ofrece al usuario información actualizada sobre avistamientos,
superpuestos como iconos en un mapa geográfico y, al hacer click sobre uno de
ellos, muestra información más detallada.

También permite realizar búsquedas con distintos filtros, como país, tipo, o rango de tiempo.

Por un lado, los generadores de datos (\textit{scraping}, datos estáticos) se encargan de poblar periódicamente los últimos datos. El \textit{frontend} es el encargado de realizar las peticiones al \textit{backend}, el cual a su vez realiza las consultas pertinentes a las bases de datos y las APIs.
