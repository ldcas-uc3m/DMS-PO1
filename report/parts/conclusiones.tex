\section{Conclusiones}
% Este último apartado destacará los objetivos alcanzados, los
% problemas encontrados durante el desarrollo de la práctica y las lecciones
% aprendidas.

Durante la realización de esta práctica se ha logrado cumplir todos los objetivos iniciales propuestos.

\begin{itemize}
    \item Desarrollo de un backend y base de datos muy potente usando Rust y Mongo, capaz de almacenar y manejar grandes cantidades de datos a grandes velocidades.
    \item Desarrollo de importación, conversión y almacenaje de datos mediante web scraping usando Python
    \item Desarrollo de importación, conversión y almacenaje de datos mediante ETL de datos estáticos (en CSV) usando Python
    \item Desarrollo de importación, conversión y almacenaje de datos mediante API usando Python
    \item Desarrollo de un frontend con un mapa interactivo, capaz de extraer datos y mostrarlos de forma efectiva.
\end{itemize}

Se hallaron numerosos problemas, que fueron resueltos durante el desarrollo de la práctica:
\begin{itemize}
    \item Dificultades respecto a la definición de la estructura de la base de datos 
    \item Dificultades a la hora de pulir la interfaz del frontend y tratar las llamadas a API de Mapbox
    \item Dificultades a la hora de scrapear una página web dinámica, la mayoría de recursos para scrapeo de HTML no funcionan con páginas Javascript.
    \item Dificultades a la hora de encontrar plataformas de API para extraer localizaciones precisas a partir de localizaciones imprecisas.
    \item Dificultades a la hora de tratar con las conversiones de datos al formato correcto
    \item Difilcutades a la hora de dockerizar el sistema
\end{itemize} 

A lo largo de la práctica hemos aprendido mucho sobre como tratar datos masivos, y consideramos que hemos tratado con éxito los objetivos del curso, superponiendonos a los problemas hallados.
