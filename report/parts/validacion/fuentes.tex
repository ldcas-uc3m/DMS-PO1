\section{Fuentes de datos}

Podemos dividir las distintas fuentes de datos en tres tipos, dependiendo de qué proceso vamos a seguir para su extracción.


\subsection*{\textit{Web scraping}}
\begin{itemize}
  \item UFO Stalker \cite{ufostalker-scraping}: [CONFIRMAR] Un API que proporciona datos sobre avistamientos reportados, mostrando avistamientos en un mapa en tiempo real.
  \item MUFON (Mutual UFO Network) \cite{mufon-scraping}: [CONFIRMAR] MUFON es una de las redes más grandes de investigación de OVNIs. Proporciona un servicio API donde puedes obtener datos sobre avistamientos reportados.
  \item ESA Sky Data Hub \cite{esa-sky-scraping}: Plataforma de datos espaciales que incluye imágenes del espacio profundo
  \item NASA Astronomy Picture of the Day (APOD) Random \cite{nasa-apod-scraping}: Acceso aleatorio a la colección de imágenes astronómicas diarias proporcionadas por la NASA.
\end{itemize}


\subsection*{Datos estáticos}
\begin{itemize}
  \item NUFORC (National UFO Reporting Center) Dataset \cite{nuforc-data}: El National UFO Reporting Center es una base de datos que contiene reportes de avistamientos de OVNIs desde la década de 1950.
  \item SETI (Search for Extraterrestrial Intelligence) Data \cite{seti-open-data}: SETI ofrece algunos conjuntos de datos de búsqueda de inteligencia extraterrestre. Aunque no tienen una API abierta, algunos datos están disponibles para descarga.
  \item ESA (European Space Agency) Open Data \cite{esa-open-db}: [CONFIRMAR] La ESA proporciona una serie de datos abiertos que incluyen imágenes satelitales, mediciones climáticas, y otros tipos de datos espaciales.
  \item SatNogs Dataset \cite{satnogs-db}: Base de datos unificada de objetos espaciales artificiales (satélites y naves espaciales)
\end{itemize}


\subsection*{APIs externas}
\begin{itemize}
  \item NASA open-access APIs\cite{nasa-open-api}:La NASA ofrece una variedad de APIs que cubren datos astronómicos, imágenes, videos y mucho más.
  \item SatNogs API \cite{satnogs-api}: API para extraer datos de la base de datos unificada de objetos espaciales artificiales (satélites y naves espaciales)
  \item NY2O API \cite{ny2o-api}: API de accessos limitados (1000 peticiones/h) sobre objetos espaciales para extraer info TLE (https://en.wikipedia.org/wiki/Two-line_element_set), posición futura o localizaciones terrestres que sobrevolara
  \item Google Maps API \cite{google-maps-api}: APIs de mapas de Google que te permite renderizar mapas interactivos con coordenadas geográficas.
  \item Mapbox APIs \cite{mapbox-api}: Proporciona mapas interactivos y herramientas de geolocalización personalizables.
  \item NASA Image and Video Library API \cite{nasa-media-library-api}: Proporciona acceso a una vasta colección de imágenes, videos y audios relacionados con misiones espaciales de la NASA.
  \item NASA Astronomy Picture of the Day (APOD) API \cite{nasa-apod-api}: Acceso selectivo a la colección de imágenes astronómicas diarias proporcionadas por la NASA.
  \item Sentinel Hub API \cite{sentinel-api}: Acceso selectivo a la colección de imágenes satélitales terrestres de los satélites Sentinel de la ESA
\end{itemize}
